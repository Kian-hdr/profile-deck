# Changelog

## 0.2.1 (build 31)

First public direct-download release. Profile Deck provides a native manager,
menu-bar switcher, optional floating tabs, profile-specific client launch and
usage previews, reviewed configuration actions, MCP sign-in routing and
copy-and-open handoffs. It preserves separate provider credentials and histories.
The editable Icon Composer artwork uses blue cards on a dark navy background,
with system-generated dark and monochrome appearances.

This release removes installation-specific profile discovery defaults from the
public source and disables the unpublished in-app update feed. Future releases
can be installed through GitHub or Homebrew. See the release notes for tested
versions and remaining UI and provider-compatibility limits.
