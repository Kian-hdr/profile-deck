# Security

Report a security concern through [GitHub private vulnerability reporting](https://github.com/Kian-hdr/profile-deck/security/advisories/new). Do not post credentials, OAuth links, account data or private diagnostics in a public issue.

Profile Deck stores manager metadata locally and uses separately installed official clients for account operations. See [PRIVACY.md](PRIVACY.md) for data boundaries. Security fixes should use disposable profile fixtures and preserve existing user folders and credentials.
