# Contributing

Profile Deck is GPL-3.0-only. Please open an issue before a large behavior or compatibility change. Keep patches focused, preserve account isolation and run `./script/test.sh` on an Apple silicon Mac with macOS 26 or later.

Use synthetic fixtures. Never include real API keys, OAuth links, profile homes, account databases, browser data, conversations, private diagnostics or screenshots showing them in an issue or pull request. The official ChatGPT/Codex client is a separate dependency and must not be copied into this repository.
